Uma clínica de especialidades médicas deseja informatizar seu processo de triagem e organização das filas de atendimento, garantindo a identificação de pacientes que possuem prioridade de chamada.
Criei um  um sistema de gerenciamento de senhas que permita cadastrar pacientes que classificá-los conforme regras de prioridade estabelecidas para a atividade e controlar a ordem de atendimento.
